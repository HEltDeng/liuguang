# 第一周访谈主持卡

目标：找到新生最近一次需要同校同专业经验时，实际找了谁、花力气在哪里、最后怎样判断有用。11/15 前访谈 5–8 位年满 18 岁的非团队成员，覆盖准留学生、在读生、校友。每次 25–30 分钟；团队人工主持。先完成同意，再记录。不要把提纲里的例子记成用户的话。

| 时间 | 主问 | 追问与观察 |
|---|---|---|
| 0–3 分钟 | 你现在处在什么留学阶段？今天有可以跳过的问题，也可以随时结束。 | 只记阶段和匿名编号。确认是否允许笔记；不默认录音。 |
| 3–10 分钟 | 回想最近一次你想向人请教，或别人来请教你的具体事情。请从事情发生前讲起。 | 当时要做什么？先去了哪里，接着做了什么？第一次回复是否解决了问题？哪些信息没找到？ |
| 10–16 分钟 | 为什么联系那个人？怎么知道对方的经历和问题有关？ | 学校、专业、修课时间各起了什么作用？问不到时怎么办？答疑的人什么时候会婉拒？ |
| 16–21 分钟 | 最近一次保存、转发或放弃一段经验是什么时候？ | 谁写的？适用于哪一届？怎样核实？有无后来者再次问同一件事？ |
| 21–26 分钟 | 哪些信息愿意让同专业的人看？哪些只愿意私聊？ | 如果把问答做成经验卡片，谁应该看草稿、谁能修改、谁能撤回？不分享也可以。 |
| 26–30 分钟 | 复述一个具体困难，请对方纠正。还有哪个重要环节我没问？ | 区分亲历与推测；仅在本人另行同意时约回访。 |

准留学生追加：当时最想找什么经历的人？在读生追加：哪次你拒绝了求助，是什么原因？校友追加：毕业后哪些经历仍可分享，哪些容易过时？

纪要模板：批次、匿名编号、阶段、问题情境、实际动作、依据、结果、反例、主持人不确定处、授权范围。原件本地私存；不收学号、联系方式或群聊截图。AI 聚类需另获授权：把每条去标识化观察编为 O 编号，输出“主题—依据编号—反例—待确认”，没有依据不归类。人工补充“保留/改写/删除、理由、复核人和日期”。
