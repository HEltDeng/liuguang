# 第一周招募包（由团队发布）

朋友圈：如果你正准备出国、正在海外读书，或已经毕业，我想听听你上一次向学长学姐问课程、住宿或开学准备的经过。我们在做「留光」，找年满 18 岁的同学聊半小时。可以跳题，不需要报名材料，愿意的话私下联系我。

学校群：想请同校同专业的新生、在读生和校友分别聊聊：最近一次关于课程或入学的问题，你找谁问，最后解决了吗？留光团队做一轮半小时的成人访谈，不用在群里留下个人信息。有意愿请私下联系发布人，先看知情说明再决定。

小红书：开学前那个具体的问题，你最终找到了谁？我们在做「留光」的第一轮访谈，想听准备 1–2 月入学、已获明年秋季录取、在海外就读或已毕业的同学讲一次亲历。仅限 18 岁以上，约半小时，不收作品、申请材料或学校账号。愿意参加可以私下联系。

筛选（人工私下询问，不建公开名单）：是否满 18 岁，是否项目组成员；准留学/在读/校友；自愿提供学校和专业用于排期的最小分类；可聊的课程、开学、校园主题；是否愿意参与半小时访谈、第二阶段七天使用或贡献本人有权分享的经验；可联络时间段。未成年、团队成员不计入测试。拒绝任意可选项不影响访谈。真实联系方式与研究编号分开，仅由主持人本地保管。先按相同专业凑齐两位愿意答疑者，再邀请对应新生。
