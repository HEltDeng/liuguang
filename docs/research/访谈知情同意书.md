# 留光成人研究访谈知情同意书 v0.1

用途：约半小时的研究访谈，了解学生如何寻找同校同专业的人、判断经验能否采用。参加自愿，可跳题、暂停、退出；不会影响获得任何服务。此份仅适用第一周人工访谈，不包含注册测试、模型处理、跨境提供或公开展示。

主持人先填写并向参与者出示：负责团队或个人 ______；联系与撤回渠道 ______；访问笔记的成员 ______；本地加密存放地点及所在地区 ______；访谈日期 ______。未填完整不收集。仅在确认本次安排不涉及跨境提供时使用此版。其他情形先补齐告知、审查和单独同意。

仅记录匿名编号、学习阶段、找人/找经验的过程、遇到的困难和建议。请不要提供姓名、手机号、身份证明、学校账号或第三方聊天内容。小专业、时间和故事组合也可能让人被识别；主持人会进一步概括。笔记和同意记录分开保存，仅上述成员访问。拟于访谈后 30 天内删除可回溯的原始笔记和编号对照；此前可凭编号联系团队查阅、更正、复制或撤回。撤回后停止使用并按申请处理可定位材料；已经不可逆匿名化的汇总无法按人定位。任何延长保存先重新告知。

请逐项手动选择，任何选项都不预先勾选：

- [ ] 我确认已满 18 周岁，了解目的、资料范围和权利，自愿接受访谈并同意主持人做上述笔记。
- [ ] 可由上列团队成员在本地阅读去标识化纪要，形成团队内主题归纳。

不录音、不录像。录制、模型分析、将问答转为经验卡片、引用原话或向评委/公众展示，均不能由本页代为授权；如确有需要，须事前单独说明接收者、内容、用途、保存和撤回方式，并再次征求同意。届时拒绝不影响本次访谈。
