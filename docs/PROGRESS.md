## 2026-11-28 双人连接

本地没有 Docker 或 Postgres。迁移文件按 Postgres 书写，开发、测试和 CI 用 PGlite 执行同一份 SQL。`DATABASE_URL` 以 `postgres://` 或 `postgresql://` 开头时改走 Postgres。合成邀请码 `M1-SAMPLE` 注册的账号带 `isSample`。正式环境拒绝这个邀请码。

权限由服务端校验，并用数据库触发器挡住“已决定的邀请被改状态”和“未接受就插入消息”。单元测试直接打这些接口；去掉条件更新或触发器后，对应断言会失败。浏览器测试使用两个独立的浏览器上下文，合成账号，不把结果当成真实参与。

模型未配置。画像整理和同校筛选的 `source` 是 `rules`，文案写明不是模型输出。经验卡片和语义重排接口返回 `501 reserved`，说明见 [设计笔记](design/m1-reserved-endpoints.md)。

离线演示在恢复带引号的草稿后，`核对并发布` 的 `data-review` 仍是 `draft"1`。原先断言在点击资源库后立刻数按钮，视图有时还没画完，所以计数是 0。测试改为等按钮出现后再断言。这是测试时序，不是草稿被滤掉，也不是属性转义错误。
